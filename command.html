サーバー生活を便利にするコマンド

プレイヤー用コマンド

サバイバル生活を便利にするためのコマンドです。

移動・テレポート系 (Essentials)

  • /tpa <プレイヤー名>
    指定したプレイヤーにテレポートを**リクエスト**します。
  • /tpaccept
    /tpa のリクエストを承認します。
  • /tpdeny
    /tpa のリクエストを拒否します。
  • /back
    最後にテレポートした場所、または死んだ場所に戻ります。
  • /sethome
    現在地を[ホーム名]として設定します。
  • /home
    設定したホームにテレポートします。
  • /spawn
    サーバーの初期スポーン地点に戻ります。
  • /warp
    運営が設定した公共施設へ移動します。

領地・保護・ログ系 (Territory / Tianyan)

  • /tty
    自分の領地として設定します。(事前に保護したい範囲の座標をメモする必要があります。)
  • /tygui
    監査ログを**GUI（画面操作）**で確認します。荒らしの特定に便利です。（Tianyan）
  • /ty x y z <時間> <半径>
    **チャット**で検索し監査ログを確認します。（上級者向け・Tianyan）

経済・コミュニケーション (UMoney / Essentials)

  • /um
    自分の所持金（マネー）を確認します。
  • /um → <送金- ｵﾝﾗｲﾝ/ｵﾌﾗｲﾝプレイヤー>
    指定したプレイヤーにお金を送金します。
  • /um → <お金ランキング>
    所持金のサーバー内ランキングを確認します。
  • /msg <プレイヤー名> <内容>
    指定したプレイヤーに個人メッセージ（DM）を送ります。
  • /ping
    サーバーとの接続遅延(Ping値)を確認します。
  • /notice
    サーバーからのお知らせを確認します。

ロールプレイ系 (RolePlay)

  • /e <アクション>
    チャットにアクション（感情表現）を送信します。（例: /e happy, /e wave）

管理者用コマンド

サーバーを管理・運営するためのコマンドです。（OP権限が必要）

サーバー管理 (Essentials / U_Backup)

  • /broadcast <メッセージ>
    サーバー全体にアナウンスを送信します。
  • /kick <プレイヤー名> [理由]
    プレイヤーをサーバーからキックします。
  • /ban <プレイヤー名> [理由]
    プレイヤーをBANします。
  • /unban <プレイヤー名>
    プレイヤーのBANを解除します。
  • /gamemode <モード> [プレイヤー]
    ゲームモードを変更します。
  • /tp <対象> [目的地]
    プレイヤーを強制的にテレポートさせます。
  • /backup
    サーバーデータのバックアップを作成します。(U_Backup)

経済・領地管理 (UMoney / Territory)

  • /um → <ﾌﾟﾚｲﾔｰの経済を管理> → <ﾌﾟﾚｲﾔｰ名> → <経済を変更>
    プレイヤーの所持金を指定した額に設定します。
  • /optty set if_[bomb/break/build/damage/jiaohu/tp] false/true
    他人の領地を強制的に管理します。
  • /optty reload
    領地プラグインの設定をリロードします。
